# 单边行情识别（独立研究任务，2026-11-09）

> 用户要求：不能只用波动率；放量相对前 1 h / 其他窗口中位数超过 2σ、4σ 等都要测；要**彻底**研究，目标是**做到**单边识别，方法不限。
> 用途：给 P3 急跌接针（及任何 maker 策略）一个因果可用的「现在别接」开关；与已验证有效的「止损后熔断」叠加。

## 1. 先定义要识别的东西

单边不是一个主观标签，用三个可度量的目标定义，全部在 1 分钟网格上、以 t 时刻为起点：

| 目标 | 定义 | 为什么用它 |
|---|---|---|
| Y1 路径单边 | 未来 h ∈ {15, 30, 60} min 内 \|收益\| ≥ k·σ_1min·√h（k ∈ {2, 3}），且最大回撤（相对终点方向）≤ 收益的 1/3 | 纯行情定义，与策略无关 |
| Y2 策略受害 | 未来 60 min 内 P3 会出现止损类出场（价格止损或到时亏损出场） | 直接对应亏钱的时刻 |
| Y3 继续偏离 | Stage 0 口径：偏离到 1.5σ 后 120 min 内继续到 3σ | 对应金字塔深层被打穿 |

基准率：Y1 约 6~7% 的小时；Y2 约 6% 的 P3 回合；Y3 约 35~47%。

## 2. 候选特征（全部只用 t 之前的数据）

### 2.1 放量族（用户点名）
对窗口 W ∈ {1, 5, 15} min 的成交量 / 成交额，参考分布取过去 {1 h, 4 h, 24 h} 同长度窗口：
- `zV = (ln V_W − median) / MAD·1.4826`，阈值 2 / 3 / 4σ；
- 买量 σ `zB`、卖量 σ `zS`、倾斜 σ `zK = z(ln((B+ε)/(S+ε)))`（总量 ≥ 参考中位才算）、平均单笔 σ `zA`（用户 11-08 的四 σ 口径）；
- 成交笔数 σ、大单（≥ 参考 p95 单笔）占比。

### 2.2 持续性族（单边 = 同向流持续，不只是放量）
- 过去 N ∈ {5, 10, 15} 根 1 min 中同向（买卖净量符号）根数占比；
- 过去 N 根中收盘同向连续根数；
- 过去 15 min 净买卖量累计 / 总量（持续倾斜）；
- 价格一路新低 / 新高的分钟占比（过去 15 min 内创 60 min 新低的次数）。

### 2.3 价格形态族
- 过去 5 / 15 / 60 min 收益，相对 σ 的倍数；
- 区间扩张：过去 15 min 高低幅 / 过去 4 h 的 15 min 幅中位；
- 相对日内高低点、整数关口的位置；
- VWAP_day / VWAP_60 偏离（Stage 0 已有）。

### 2.4 跨所与状态族
- BN 同向同幅（Stage 0 的 sync）；BN 成交量 σ；BN 与 Bitget 放量是否同时；
- BN OI 5 min 变化（10-28 起有）、Bitget OI（11-06 起）；
- 资金费率水平与距结算时间；
- Bitget L1 自侧量 / 对侧量比、books1 单侧量相对过去 1 h 中位的缩水。

### 2.5 策略自身
- 过去 60 min 内 P3 是否发生过止损（已验证有效，作基线对照）；
- 过去 60 min P3 回合盈亏累计。

## 3. 评估方法

1. **单特征**：对每个 Y、每个 h，报 AUC、IC、按阈值（2/3/4σ）的命中率 / 误报率 / 提前量（首次触发到单边起点的分钟数）；按周（W1~W5）看稳定性。
2. **组合**：逻辑回归 + 梯度提升，按天留一（LODO）；报 OOS AUC、特征重要性、与「止损后熔断」的增量。
3. **翻译成开关**：检测器触发 → P3 之后 M ∈ {30, 60} min 不开新回合。在 34 天上**按周 walk-forward**（前几周定阈值、下一周用）计算：总净、正日、最大回撤、被挡掉的止损次数、被挡掉的盈利回合（误报成本）；与「止损后熔断 60」及两者叠加对比。
4. **样本外**：11-01~11-07 窗口（C1e 正在拉）最后验证一次，不调参。

## 4. 判定（用户 2026-11-09 口径：召回与回撤优先，误杀可接受）

- 选阈值：在「开关后总净 > 0」约束下取最大回撤最小者；给误杀金额 vs 挡掉止损金额的换算曲线；综合看 总净 / 最大回撤（基线 P3 ≈ 2.3，止损后熔断 60 ≈ 5.8）。
- 有用：walk-forward 下最大回撤显著低于熔断 60 的 31，或两者叠加再压回撤，且总净仍为正、按周符号稳定。
- 对漏掉的止损逐个列出检测器当时的特征值，回答「单边开始前有没有先兆」。
- 三个选阈值准则并排：① 净 > 0 下回撤最小；② 总净 / 最大回撤 最大；③ 挡掉止损金额 − 误杀盈利金额 最大。
- **收益曲线图**（用户要求）：基线 P3 / 熔断 60 / 最优单特征 / 最优组合 / 检测器 + 熔断 / 安慰剂 B 六条逐日累计净值叠加，附回撤子图，34 天 + 样本外竖线分隔。
- 无用：所有特征对 Y1/Y2 的 OOS AUC ≤ 0.6，或开关后总净下降。两种结果都如实报。
