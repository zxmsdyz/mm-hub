### 1.1 C9 Stage 0 预登记（2026-11-10，看结果前写定）

- **样本**：① Bitget 全部公开成交的被动方（touch 现有挂单者口径，不依赖引擎，主样本）；② 修后引擎 D3 模拟成交（若成交明细现成）；③ Run A 实盘成交（11-07，n≈2,200，只作对照）。
- **窗口**（每窗 ≤ 7 天）：BTC 开发 10-15~10-21（+3.0% 周）、验证 10-22~10-28（−3.3% 周）；ETH 同验证周；资费 / 溢价项用 Bitget mark 流 11-06 起的天数。
- **倾斜代理**（都取成交前 100 ms 与 1 s 的 as-of 值，交易所时间戳对齐）：基差 b = mid_bg − mid_bn 拆成**慢分量**（1 / 5 / 60 min 滚动中位相对更长窗的偏离）与**快分量**（b − 慢分量，即 BN 领先部分，只作控制变量）；资费符号 / 永续对指数溢价 / 到结算时间；盘口 5 bp 内两侧深度的 60 s 平均不对称。
- **读数**：按「成交方向 × 代理符号」分桶的 mo5 / mo30 / mo60 / mo300（裸 bp）、占比、按日聚类的标准误、逐周、逐品种；快分量三分位内重复一遍；时间平移安慰剂。
- **放行（全部满足才进 Stage 1 单侧报价回测）**：某代理的较优一侧桶 mo30 ≥ −0.5 bp 且占成交 ≥ 40%；两侧差 ≥ 0.3 bp 且按日聚类 |t| ≥ 3；开发周选出的代理与符号在验证周同号、ETH 同号；控制快分量后不消失；安慰剂 ≈ 0。任何一条不满足即 DROP。

## 3. 当前结论（2026-11-09 更新）

在 BTC / ETH / SOL、maker −0.5 bp / taker 1.5 bp 这组约束下，做过的 13 轮（touch 做市及门控、轻库存、冲击-回归、急跌接针 4 轮、RPI 深挂、散户占比门控、VWAP / 基差锚错位回归 3 轮、顺势 maker）**没有一个在样本外稳定赚钱**。C8 的诊断把原因说死了：**价格偏离之后的路径是 50/50，没有可被 maker 利用的方向信息**；我们成交后看到的 0.8 bp 延续，是被成交挑出来的那一半，不是市场本身的漂移。所以任何「等错位、博回归」或「顺趋势」的 maker 方案，在这三个品种上都只剩逆向选择这一个确定的负项。共同原因：我们的成交对手绝大多数是 API 知情流（SOL：被 API 吃 −0.76 bp / 被散户吃 +0.32 bp），而这三个品种恒为 1 tick 价差，没有价差收入去抵。

只差多少：现有挂单者在 touch 被成交的每笔净（含 0.5 返佣）SOL −0.19、ETH −0.32、BTC −0.36（实盘）⇒ 要打平，maker 返佣需要约 0.7 / 0.8 / 0.9 bp。

能改变符号的不是新因子，而是约束本身，需用户决定：
1. 费率：争取更高返佣档（做市商计划 / LIP），或对 RPI 申请做市商资格（RPI 本身已证明把毒性从 −1.2~−3 压到 ≈ 0，但 0 费率下不够）。
2. 品种：放开 tick 0.5~2 bp 的中流动性合约（XRP、SUI 等），半价差 0.25~1 bp 是 BTC/ETH/SOL 没有的结构性收入（2026-11-06 用户已否决，记录在 strategy §2）。
3. 场所：换到我们不是跟随者、或散户占比更高的交易所。
