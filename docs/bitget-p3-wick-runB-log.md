### 机制核对（全部符合规格）
- 梯子价：L0 = `low`（确认时比 mid 低 2 bp），L1 / L2 再低 5 / 10 bp；止盈 = C ± 5 bp 向不利方向取整，C 变即重挂；止损在 C ± 40 bp 触发；止损后 COOLDOWN 正好 60 min，期间 11 个触发被跳过。
- 安全阀 `daily_loss_stop_usdt = 1.5`：11-09 止损后日净 −0.92，再止损一次当日就停新回合（回测没有这个阀）。

### 发现的问题
1. **已修**：成交流 stale（3 s 无成交）会撤梯子。11-09 17:08、17:19 两个回合分别在挂出 9.4 s、95 s 被撤（规格 180 s）。实现方 `c4bb9c9ea` 修复，17:44 UTC 重启后的梯子都活满 180 s。这两个回合不计入成交率。
2. **回合行漏出场手续费**（实现方已记 backlog）：多层回合 `wick_round.net_usdt` 止盈少记 0.5 bp、止损少记 1.5 bp；`daily_pnl_usdt` 稍后补齐。本日志一律按成交重算。
3. **`queue_ahead` 全为 0**（42 张单）：只有 L1 行情，挂在 touch 外的价位读不到前量。交接 §5 第 2 项的「queue_ahead 分桶成交率」量不了。
4. **止盈单「被吃速度」在 lot 0.001 量不出来**：5 张止盈全是一次性全成，没有部分成交。改用采集器的 Bitget 公共成交离线算「止盈价被触及后 N 秒内穿过该价的成交量」，不用改实盘代码。
5. `trade_stale` 2,612 次、占时 11.5%（阈值 3 s）。修复后没有触发因此被丢（17:44 之后跳过原因只有 busy / cooldown），仅记录。
